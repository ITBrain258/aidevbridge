aidevbridge 0.3.7 is a security update: the SSH library and three other dependencies move to versions that fix published advisories.

- **SSH library (russh 0.65.4):** fixes six advisories published on 21 November 2026. Three concern an SSH client: a server whose host key you accepted could make the app's memory grow with repeated failure messages (GHSA-ppq4-8rhp-9xrq, medium); the server's host key and signature are now checked against the algorithm agreed for the connection (GHSA-66vf-xq4p-pg7q); and replies to opening a channel count only for a channel that is waiting for one (GHSA-7qgr-cjxw-6vjf). The other three do not affect the app.
- **RSA keys (rsa 0.10.0):** fixes the "Marvin" advisory RUSTSEC-2023-0071, which the app had accepted because it signs with blinding and never decrypts. An RSA key whose two primes differ in length is now refused with "invalid RSA key components"; keys made with `ssh-keygen` are not affected.
- **url 2.5.9 and cookie 0.18.3,** which come in through Tauri: fix RUSTSEC-2026-0592 and RUSTSEC-2026-0594.

Nothing else changes.
