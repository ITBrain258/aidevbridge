aidevbridge 0.3.2 is more forgiving on a shaky network, fits a phone screen better and shows errors that used to stay silent.

- **Connections:** a short network stall, such as a switch between Wi-Fi and mobile data, no longer drops the control connection to a host. A host with a password no longer has to log in again because of it.
- **Android:** the settings, the error message and the session actions fit a phone screen, and buttons are large enough to tap.
- **Errors:** an unexpected error shows a message instead of leaving the window empty, and the error message is readable when it lies over a terminal.
- **Screen readers:** connected, connection failed and connection lost are announced, with the name of the host.
- **Hosts and sessions:** "New session" accepts a name that only exists in your own tmux. Editing a host no longer loses its key file when you save quickly. A host added while the dialog closes appears at once. Shortcuts no longer act behind the host key question.
- **Key files:** only a regular file of up to 64 KiB is read as a key file.
