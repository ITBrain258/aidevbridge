aidevbridge 0.3.4 stops clicks in the sidebar from getting lost, keeps browser keys out of the terminals when screen reader support is on, and gives Android a way back to a host whose key changed.

- **Sidebar:** a click on a row no longer goes unnoticed when the list updates at that moment, for example because an agent's status changed. After moving through the waiting lane with the keyboard, the first click on another row used to be lost every time.
- **Screen readers:** with "Screen reader support" on, Ctrl+R and other browser keys no longer reload the app or open browser functions when the screen reader has put focus on a line of a terminal.
- **Android:** when a server gets a new host key, for example after a reinstall, remove the host in the app and add it again: the app forgets the old key and asks you to confirm the new one. Before, the only way out was to clear the app's data, which also deleted the keys made in the app. On Windows and macOS nothing changes; there `ssh-keygen -R` removes the old key as before.
