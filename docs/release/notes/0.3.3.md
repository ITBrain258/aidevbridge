aidevbridge 0.3.3 lets screen readers read the terminals, connects many hosts at once without errors and makes dialogs easier to use on a phone.

- **Screen readers:** a new switch, Settings → Terminal → Accessibility → "Screen reader support", lets screen readers such as NVDA, Narrator, VoiceOver or TalkBack read the text of the terminals. It is off by default, because it slows the terminals down when programs print a lot.
- **Many hosts at once:** when more than eight hosts connect at the same time, for example a restored workspace at start or after standby, the ninth and later ones no longer fail with "Too many … are already pending". They wait a moment for their turn.
- **Android:** text fields, lists and buttons in dialogs and on the first start are as large as the other touch targets.
- **Stability:** an internal error in one command no longer leaves every later command failing until the app is restarted.
