aidevbridge 0.3.6 makes the first start clearer and tells you when a host's shell writes into the answers.

- **If your host's shell prints text on every SSH command:** the app now says so and shows no session list for that host, instead of showing the text as sessions. This is the case with, for example, an `echo` at the top of `~/.bashrc` or in `~/.zshenv`. The message quotes the first line; remove the output or print it only in interactive shells, and the list is back. What such a host listed before was wrong. If the shell only writes messages to standard error, the list stays, by name, and the status "Unknown" names the shell as the reason.
- **First start:** the host check says its result in the heading ("build-box is ready" or "is not ready yet") and in words on each line. "Check again" repeats it on the same connection, so after installing tmux you neither connect again nor retype a passphrase or password. Without suggestions the start is called "Add your first host" and says in one sentence what a host is. Under a suggestion that does not connect, "Edit details" opens the form with its values.
- **Sign-in messages:** when the host does not accept your key, the message says so and names what to check: the user name and the public key in `~/.ssh/authorized_keys`. Before, three different cases all read "The server does not offer this authentication method."
- **A host without sessions:** a connected host with an empty list shows a labelled "New session" button, and a host you have just saved is expanded. On a phone the list of hosts used to cover the only button with a word on it.
- **Many sessions on a slow connection:** a host with about 20 sessions on a slow link never showed its list. Each command now has 15 seconds and the whole list 60.
- **Working directory:** a folder that ends in `;` is refused, with the reason at the field. tmux would have started the session somewhere else without a message.
