aidevbridge for Windows x64

Extract the complete ZIP into a folder, then start aidevbridge.exe.
Keep the licenses folder beside the executable. Open licenses/index.html
to read the included license texts and notices without internet access.

This ZIP requires an already installed Microsoft Edge WebView2 Evergreen
Runtime. It does not download or install the Runtime. If it is missing,
install WebView2 through Microsoft's official deployment instructions
before starting the application.

The ZIP is an execution without the application installer, not a separate
portable-data mode. aidevbridge uses the same normal per-user settings and
SSH-related files as the installed application. Removing this extracted
folder does not delete those user files or the shared WebView2 Runtime.

their separate terms. Build artifacts do not by themselves establish

for the actual development status and the supported connection and
authentication setup.
